# Portafolio Aero 2

Portafolio del proyecto de control avanzado para la plataforma Quanser Aero 2. El sitio presenta el modelo linealizado, el diseño LQR, el observador de estados y la evidencia de integración.

El informe técnico con el desarrollo de los procedimientos y resultados está disponible en `Proyecto_CAR_O26.pdf` y se visualiza desde la sección **Informe técnico** del sitio.
